- **Project-scoped certification contracts.** New operations under `/api/v1/projects/{project_id}/`: certificate build-session issuance readiness and abandonment, and process-record preparation, verification, retrieval and finalization. Every process-record call takes the build-session reference (`bsn:...`). Before the build session is finalized, prepare and finalize return `404` with code `LINEAGE_UNMAPPED`; retrieval returns `404` `PROCESS_RECORD_NOT_FOUND` until an issuance exists. Certificates that carry a `runlineage:` reference stay on the existing certification routes, which are unchanged. Error bodies are closed, including the browser-session `401` variants (`CSRF_VALIDATION_FAILED`, `SESSION_IDLE_EXPIRED`, `SESSION_ABSOLUTE_EXPIRED`, `SESSION_INVALID`). Additive: no existing operation is changed or removed.
