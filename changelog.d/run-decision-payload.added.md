- **`experiment_run.get_run_decision_payload`: run decision payload declared on an experiment-run reference; the analytics-path GET deprecated (additive, contract only).** `GET /api/v1/projects/{project_id}/experiment-runs/{experiment_run_ref}/decision-payload` (operation id `experiment_run.get_run_decision_payload`) takes the server-issued reference `^experiment_run_[0-9a-f]{32}$` and the explicit project, with no query parameters. The 200 is the new `analytics/run_decision_payload_response_schema.json` (same `data` DTO `decision_payload_schema.json`, no field added; the canonical response carries the experiment_run_ref in `data.run_id` (pattern `^experiment_run_[0-9a-f]{32}$`, overridden in the canonical schema only; the field set is unchanged); `meta`/`metadata` become bounded maps of strings, booleans, null and safe-range integers; `x-max-response-bytes` 1 MiB). Errors are the closed problems of `analytics/decision_payload_problem_schema.json`: 400 malformed reference, 401, 403, one identical 404 for a missing, foreign, ungranted, revoked or retired run, 429 and 500, and 503 as the declared outcome when the payload cannot be produced within its budget (never a partial success). `GET /api/v1/analytics/runs/{run_id}/decision-payload` stays declared, marked `deprecated` and naming the successor; the beta mounts of the view are not declared in this contract. Removal follows the backend retirement PR after the client receipt.
